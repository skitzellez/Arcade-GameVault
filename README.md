# Game Vault · Arcade

Windows arcade games on Xbox Series X|S in Dev Mode, started from [Game Vault](https://github.com/skitzellez/xbox-game-vault).

- Bring your own game dumps. No games come with this app.
- Install: in Game Vault, open an arcade game and press RT to add it with your phone, or install the `.appx` from Releases with Dev Home.
